# 审计知识库 · 网页版

一个纯静态、无后端的审计资料检索站点。两套内容，两个入口：

| 入口 | 地址 | 内容 | 访问 |
|---|---|---|--:|
| **公开版** | `/` | 审计实务、专题研究、培训与考核材料、CPA 备考笔记 | 764 篇 / 387 万字 |
| **内部版** | `/vault/` | 上述内容 + 事务所内部制度 + 第三方准则汇编 | 5,282 篇 / 3,526 万字 |

---

## 公开版

直接打开根路径即可，无需登录。支持：

- 标题 / 目录 / 摘要检索，可按分类筛选
- 全文检索（扫描全部正文，首次约 1–3 秒）
- 每篇文章可复制直链（`#p<id>`）
- 深浅色、字号调节、键盘快捷键（按 `?` 查看）

首屏只加载 551 KB，正文按需分片加载。

## 内部版

`/vault/` 的数据文件以 **gzip 压缩 + AES-256-GCM 加密** 双层处理，密钥由访问口令经 PBKDF2-SHA256（200,000 次迭代）派生，在浏览器本地解压解密。

- 没有口令：`data/*.bin` 全部是密文，无法解析出任何标题或正文
- 有口令：解锁后功能与公开版一致，只是内容更全
- 口令只在本地参与解密，不会发送到任何服务器
- 关闭浏览器标签页后需重新输入

**口令由管理员单独下发，不在本仓库中。**

## 技术构成

```
.
├── index.html            公开版入口
├── app.js                应用逻辑（两版共用）
├── data/                 公开版数据（明文：stat / tree / meta / shard_N）
├── vault/
│   ├── index.html        内部版入口（含口令解锁）
│   └── data/             内部版数据（gzip + 加密：*.bin + _key.json）
├── .nojekyll             关闭 GitHub Pages 的 Jekyll 处理
└── _build_manifest.json  构建清单（篇数 / 字数 / 分片 / 时间）
```

- 纯静态：HTML + CSS + JS，无框架、无构建步骤、无服务端
- 数据以 `stat`（统计）、`tree`（目录树）、`meta`（索引）、`shard_N`（正文分片）四类文件组织
- 首屏加载 `stat` + `tree`；`meta` 空闲预载；正文点开才加载所在分片
- 兼容 `file://` 直接双击打开（仅公开版）

## 更新

内容更新在本地完成后重新推送：

```bash
python build.py          # 重建 dist/
cd dist && git add -A && git commit -m "update" && git push
```

GitHub Pages 会在 1–2 分钟内重新发布。
